# Glossary

Short explanations of the game's terms, with the chapter that tells you more.

| Term | Meaning |
|---|---|
| Anger | A colony's discontent from 0 to 100, which sets its mood. Computer players also keep an anger value toward each empire. See [Planets and colonies](planets-and-colonies#mood) and [Diplomacy](diplomacy#how-computer-players-feel-about-you). |
| Armor | Components that are destroyed before any other component when a ship is hit. See [Combat](combat#damage). |
| Asteroid field | A field of rocks in a sector. It cannot be colonized, but it can be mined remotely or turned into a planet. |
| Attacker, defender | In a battle, an empire with nothing in the sector before the battle is an attacker; the others are defenders, and act first. |
| Base | A vehicle that cannot move. It never runs out of supply and pays half the upkeep. |
| Blockade | An enemy ship in a colony's sector stops the colony's production. See [Planets and colonies](planets-and-colonies#blockades). |
| Breathable | A planet whose atmosphere your race breathes. Other planets need domes. |
| Capital | A planet you started the game with. Its mood never gets bad enough to riot. |
| Cloak | Hiding a ship from enemy sensors. See [Ships and fleets](ships-and-fleets#cloaking). |
| Colony type | A label for a colony's purpose, used by ministers and computer players. |
| Combat turn | One round of a battle. A battle lasts at most 29 with the stock settings. |
| Component | A part of a design: a weapon, an engine, armor, a sensor and so on. |
| Conditions | How pleasant a planet is, from Deadly to Optimal. It changes population growth. |
| Contact | Having met another empire. You need contact for messages, treaties and intelligence. |
| Culture | A society-wide set of bonuses and penalties, chosen with your race. |
| Design | A hull with its components: the blueprint of a ship, base or unit. See [Ship design](ship-design). |
| Domed | A colony on a planet whose air some of its people cannot breathe. It has far fewer facility slots and room for people. |
| Emergency build | A queue mode that builds at 150 % for a while, followed by a slow period. See [Construction](construction#build-modes). |
| Experience | Skill a crew or fleet gains by destroying enemies, which improves its aim. |
| Facility | A building on a planet: mines, farms, research centres, space yards and more. |
| Fleet | Ships that move and fight together. See [Ships and fleets](ships-and-fleets#fleets). |
| Formation | The arrangement of a fleet's ships in battle. |
| Game date | The year, starting at 2400.0. Each turn adds 0.1. |
| Ground combat | The fight between invading troops and a planet's defenders. See [Ground combat and capture](ground-combat-and-capture). |
| Happiness type | How a race's people react to events such as war, peace and losses. |
| Homeworld | Your empire's first planet. |
| Hull | The frame of a design, which sets its class and how much fits in it. Also called a ship size or unit size. |
| kT | Kilotons, the unit of size for hulls, components and cargo. |
| Maintenance | The upkeep your ships and bases cost every turn. See [Economy](economy#maintenance). |
| Militia | Defenders raised from a planet's people when it is invaded. |
| Minister | A part of the computer that runs part of your empire for you. See [Computer players and ministers](computer-players-and-ministers). |
| Mothball | Store a ship out of service, with no upkeep. |
| Mount | A variant of a weapon component with more damage, range or accuracy, for larger hulls. |
| Movement points | How many sectors a ship can move in a turn: its speed. |
| Obscuration | How hard an object is to see. A sensor of at least the same level sees it. |
| Point-defense | Weapons that fire automatically at fighters, drones and missiles. |
| Population | The people of a colony, counted in millions (M). |
| Prototype | A design that has never been built. Only prototypes can be edited. |
| Racial points | The budget for designing a race's characteristics and traits. |
| Rate | How much of each resource a construction queue can spend per turn. |
| Repeat orders | A ship option that repeats its order list forever. |
| Resupply depot | A colony facility that refills ships in its sector with supplies. |
| Ruins | Remains of an ancient civilization on a planet, which give technology to whoever colonizes it. |
| Score | A measure of an empire's fleet, production and technology. See [Score and victory](score-and-victory). |
| Sector | One square of a star system's 13 by 13 grid. |
| Seeker | A missile or torpedo that flies to its target. |
| Sensor | A component or facility that sees objects with higher obscuration. |
| Shields | Protection that absorbs damage before the hull is hit. Shields are full at the start of every battle. |
| Shockwave | The result of destroying a star: everything in the system but its warp points is destroyed. |
| Space yard | A facility or component that lets you build ships. |
| Spaceport | A facility that ships a system's output to your empire. See [Economy](economy#spaceports). |
| Strategy | Instructions that tell ships how to fight when the computer is in control. See [Combat](combat#strategies). |
| Supply | Fuel and ammunition. Ships use it to move, fire and cloak. See [Supply, cargo and repair](logistics#supply). |
| System | A star system: a grid of sectors with its stars, planets and warp points. |
| Tech area | A field of research with levels. See [Research](research). |
| Tonnage | The size of a hull, in kT: how much it can hold. |
| Treaty | The formal relation between two empires, from War to Partnership. See [Diplomacy](diplomacy#treaties). |
| Unit | A fighter, satellite, mine, drone, troop or weapon platform. See [Units](units). |
| Value | A planet's richness in minerals, organics and radioactives, as a percentage. |
| Warp point | A link to another star system. See [The galaxy](galaxy#warp-points). |
| Waypoint | One of ten named places you can send ships to quickly. |
