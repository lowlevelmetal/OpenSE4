# Main window & maps audit (analyst findings, plain language).

1. DIFFERENT M — Ship selection cycle: Space, Ctrl+N, Ctrl+B and the selector arrows run the same command (same ships). Candidate = own ship (never unit groups); max speed > 0 and not mothballed (bases/mothballed never visited); turn-based: has movement left; simultaneous: has no orders; first order is not Sentry (always applied, so sentried ship with movement left skipped in turn-based). Then the four Next/Previous empire options filter. "Stop once per location" uses a visited-places table cleared when the cycle wraps, or player or direction changes. Ours: only Space filters and only forwards (main_window.cpp:2127 cycleVehicle(...,true)); Ctrl+N/Ctrl+B (2128-2129) and arrows (1451) idleOnly=false visit every own non-unit vehicle incl bases/mothballed; nothing skips Sentry; no filtered previous cycle. Spec 06 §2.3 has movement/no-orders rule (code gap); add Sentry skip, speed/mothball exclusions, same-cycle fact.
