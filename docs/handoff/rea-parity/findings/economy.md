# Economy audit (analyst findings, plain language)

1. DIFFERENT M — Complete AI is not a latch in the original. Complete AI On = bulk: lights all 25 minister lamps + "use individual ministers for newly built vehicles", sets every own ship/planet/fleet flag on; Off reverses. Afterwards Select None / single minister off / one ship's flag off take effect. Lamps applied when window closes. Ours: SetMinisters{completeAi} sets Empire::ministerAll (commands.cpp:1121) which ministerOn/controlsVehicle/Colony/Fleet (ai.cpp:494-510,1234) and underCloakingMinister (movement.cpp:1387) treat as all-on; export writes all 25 on (classic_save_export.cpp:549). Spec 02 §10: add line. Keep ministerAll for Players window / stand-in uses, Ministers window should not set it. confirmed: binary.
2. MISSING M — Units tab amount picker: left-click unit design in Set Construction Queue opens "Amount" pick list: One Turn's Worth, 1,5,10,15,20,25,30,35,40,45,50,100,150,200; Cancel adds nothing. Ships always add 1. One Turn's Worth = largest n>=1 whose from-scratch build time <= 1 turn; build time = max over resources with rate>0 of trunc(n*unitCost/rate + 0.9999) using the queue's current rate; queue rates summing to 0 -> 1; design whose computer design type is "Recon Satellite" (inferred code 35) -> always 1. Multi-Add window: same list without One Turn's Worth. Ours: buttons 1/5/10/20 (queues.cpp:910-919). Spec 02 §6.5 Units.
3. DIFFERENT M/L — Queue acceptance. Original refusals only: Facility: unknown ("no such facility"); not a planet (silent); built facilities + SUM OF COUNTS of queued facility items >= slots ("limit of N facilities on this planet"); a space-yard facility when the planet has a working yard, one queued, or its facilities give Space Yard ("limit of one Space Yard per planet"); not researched ("<name> is beyond our current technology"). Upgrade: only "already in the construction queue". Vehicle: unknown design ("no such vehicle design"); other empire's design ("we do not own the design of ..."); not buildable with current tech ("design is beyond our current technology to build"). NOT checked: colony population, ship limit (checked at completion only), space yard for ships (ships can come via Fill Queue on yard-less colony; removal pass drops them). Ours queueItemProblem (commands.cpp:1363): refuses everything at 0 pop; refuses ships at ship limit; refuses ships on yard-less colony; counts queued facility items not counts; dead "Domed colony is full" branch; AI uses it too. Spec 02 §6.5 or new acceptance subsection. confirmed: binary.

MISSING M/L — Select Colony Type picker (from Colonies->Set Colony Type and colonization) has Add Type (input "Colony Type Name", appends new non-duplicate non-empty name to empire colony types, saved) and Delete Type (removes selected). Quirk: cancelling from Set Colony Type sets the colony's type to "" (document, don't copy). Ours: both pickers only list colonyTypes (planets.cpp:843, classic_mode.cpp:1655); cmd::SetColonyTypes never issued by client. Design-type picker has same Add/Delete, missing in designs.cpp. Spec 02 §10, spec 06 §1.2.
5. MISSING L/M — Queue types are per-empire and saved in the game: Select Queue Type lists the empire's named queues; Add Type asks "Queue Type Name", stores copy of current queue; Delete Type removes; Fill appends each item with its stored count, each refused item gives its own "Warning" box with the reason from 3. Ours: per-computer queue_types.txt + built-in "Fill free slots" types (queues.cpp:585); Fill skips refused silently with a count; import drops the original's templates. Keep ours; add per-empire saved templates alongside. Spec 02 §6.4, spec 08 §3.6.
6. MISSING M/L — Strategies window: tabs Movement, Firing, Damage, Launching, Formation. Launching: pick lists Fighter Group Size (5,8,10,15,20,30,40,50) and Drones Per Target (1,2,3,5,8,10,15,20). Add asks "Enter Strategy Name", creates from built-in defaults: fighters 5, drones 3, damage percent per ship 80, others 100, "until all weapons gone" off, and Break Formation on for Carriers, Colony Ships, Fighters, Satellites, Planets, Transports, Seekers on us and Seekers on others, off for Bases, Ships, Mines, Bases (no weapons), Ships (no weapons) and Drones (categories in spec 08 §3.6.13 order; confirmed: binary). Ours: Launching only fighters slider; Drones Per Target only raw text if key exists (empire_status.cpp:831); Add copies first data-file strategy named "New Strategy". Copy/Remove are ours, fine. Spec 04 §16.

Ours uses larger value everywhere (commands.cpp:422) and type popup previews it. Spec 02 §6.6 needs correcting.
8. DIFFERENT L — Clear Queue resets items, On Hold, Repeat, the automatic Move To waypoint and progress; keeps Emergency and its turn counter. Same clear runs on diplomatic planet transfer, a ship whose yard stops working, some intel/package paths. Ours: clearQueue keeps autoWaypoint (queues.cpp:1166); ship cloak clears only items (movement.cpp:1568). Spec 06 §7 Q28, §1.8.2 omit waypoint.

Ground capture (combat_ground.cpp:362) same; original's capture path not verified.
