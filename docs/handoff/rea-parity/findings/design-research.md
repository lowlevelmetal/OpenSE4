# Designs/research/intel audit (analyst findings, plain language).

1. MISSING M — "Select Design Type" list window (from Create Design's Design Type box): lists empire's design types, one "Name" column; Add Type asks "Design Type Name"; added at end if not empty, not already in list, list < 250 entries; otherwise nothing, no message. Delete Type removes selected, no confirmation, no check of designs using it. Cancel or picking nothing leaves design with no type (box reads "Design Type"). Ours designs.cpp:877-886 plain popup; cmd::SetDesignTypes exists (commands.cpp:1080) but unused. Spec 06 §1.2 / §7 Q94.
2. DIFFERENT M (answers Q99(c)) — Intelligence adding a project: 12 queued -> nothing. Intelligence Defense added at once with no target. Every other project first opens "Select Empire": living empires we have contact with, not ourselves, no "Any" row. Then a second list window by project Type, each starting with an "Any ..." row: "Select Ship" ("Any Ship"): target empire's vehicles we can see now, sorted by name; used by seven ship sabotage types (Damage, Lose Movement, Lose Supply, Rebel, Experience Change, Cargo Damage, Orders Change). "Select Planet" ("Any Planet"): target's planets we can see, sorted by name; planet types Conditions Change..Facility Damage, and Planet - Info. "Select Technology" ("Any Technology"): tech areas the SPYING empire can research (prereqs met, allowed), alphabetical; Research - Steal. "Select Empire" ("Any Empire"): our contacts except target; all five politics types: Disrupt Trade, Intercept Messages, Fake Messages, Treaty Info, Prevent Messages. All other types (Concentrations, Construction Info, Planet - Locations, both Points types, both Delete Project types, three Info types, design and log steals) no second picker. Cancel at either step adds nothing. Project box: name word-wrapped; if specific target picked, line at y 40 names it ("Any Ship" or ship/planet/area/empire name); at y 54 centred on x 65: "Against " + target empire's flag; Completion and Cost Per Turn as Research. Right-click on project row or box opens intel project report. Ours intelTargetKind (empire_logic.cpp:428) asks third empire only for Fake/Prevent Messages (others engine draws Any); third-empire list has no Any row, titled "Select Third Empire"; tech list every non-racial non-unique area data order; Any rows read "Any"; ships unsorted; box shows "vs <empire>", never target (intelligence.cpp:304); no right-click reports. Spec 06 §7 Q99(c), spec 05 §2.1.
