# Setup/scenarios audit (analyst findings, plain language).

1. MISSING M — Scenarios & tutorial (confirmed: binary unless marked):
- Files: scenario folder = Scenarios\ (or mod's folder of that name when exists). <stem>_Settings.txt read for Name, Description, Starting Game; only Starting Game used (Name/Description never shown). <stem>_Text.txt pages kept in FILE ORDER; ID ignored. If a file not found at its path, same file name tried in scenario folder. Load errors in either file -> standard error list titled "Scenario Settings Errors: <file>" / "Scenario Text Errors: <file>"; both always read; scenario doesn't start if either had errors.
- Tutorial button: stem fixed = scenario folder + "Tutorial".
- Scenario button: Load Game picker in scenario mode: title "Load Scenario"; first column header "Scenario Filename", then Date. Lists folder's *.txt whose lower-case name contains "_settings.txt", shown as name minus that suffix, CAPITALS, with file date. Change Directory and Cancel as usual. Row click -> folder+name; Cancel nothing. Starting Game always from scenario folder even after Change Directory.
- Starting, in order: switch to background music; load both files; load Starting Game with normal loader (save decides humans, style, options, victory; scenario applies no settings); set scenario flag and for Tutorial only the tutorial flag; remember stem as full path and reload the two files (the load reset them); rebuild status-bar buttons, show main window, run page check, close intro.
- Turn numbering: page's Turn absolute: matches when (game date - 2400.0) x 10 == Turn.
- Automatic pages: at start of each HUMAN empire's turn (computer-controlled never), and right after scenario starts. Page = FIRST page in file order whose Turn matches and whose For Players contains current player number; test is substring search of "<n>," inside "<list>," (player 1 also matches "11", quirk). Only that one page opens, modal; player browses series from there. Plain load doesn't show turn's page; does when a load opens the Next Player screen (hand-over files, autosaves). Simultaneous games: turn processing calls this once per living human empire -> pages pop up on host's screen; network player's machine never shows them.
- Scenario window ~416x453, no title bar. Picture: page's 128x128 Image from scenario folder at (10,10); none when field empty or "None". Title right of picture, or across top without one. "Page i of n" right-aligned just above text; i = page's index in WHOLE FILE; n = number of pages in that Series (quirk). Text: scrolling list one entry per paragraph, each indented three spaces; without picture starts at y 36. Buttons: one row of three equal: Previous, Close, Next. Previous -> file's previous page; disabled when page's Segment <= 1. Next -> file's next page; disabled on file's last page or when next page is in another Series. Esc closes.
- Re-opening: on close, index of page on screen stored as "last page shown" (initially 1). Ctrl+H reopens that page when scenario flag set and pages loaded.
- T buttons (TUTORIAL flag only): status bar T just left of minimize; every large 780x475 dialog a 20x20 T at (746,8). Both reopen last page. Ordinary scenarios Ctrl+H only.
- .gam stores scenario flag, tutorial flag, stem (full path), last page index; nothing about which pages shown. On load flags restored and files reloaded; non-scenario save resets them.
- Quirks: loading from the intro (Load Game, Resume Game) clears scenario mode after load (no pages, Ctrl+H, T); Game Menu -> Load keeps it. Game Menu -> New clears nothing (old tutorial flag/T/pages carry into new game; inferred).
- End: no scenario-specific ending; victory conditions in the save.
- Ours: Tutorial/Scenario open Learn (frontend.cpp:105-106); nothing reads Scenarios/; lesson runner's T and Ctrl+H toggle our lesson panel (main_window.cpp:1306, lesson_runner.hpp:75); no scenario window; scenario fields import-ignored (spec 08 §3.4). BLOCKER: Tutorial.gam is version 1.58; importer refuses all but 1.95 (classic_save_import.cpp:47). Binary has exactly four version gates above 1.58: 1.62 a design's computer-player template name; 1.72 options' codes and checksums; 1.78 empire options for facility-marker groups 2-12; 1.81 a strategy's drones-per-target (default 3). Supporting these reads the tutorial.
- Spec homes: new spec 06 §5.6 rules + §1.1 Scenario chooser row; spec 06 §2.2 correction (T is tutorial only and on large dialogs); spec 08 §3.4 (stem full path, last page = file index); spec 08 §5.2 (four gates); spec 01 §12 (Name/Description unused).
